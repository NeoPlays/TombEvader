# TombEvader

## Development

This Project is developed with Unreal Engine 5.6.1

To get up and running:
1. Open Terminal in you Unreal Engine Project Directory (e.g. `E:\EpicGames\UnrealProjects`)
2. Clone Repository `git clone git@github.com:NeoPlays/TombEvader.git`
3. Open `TombEvader.uproject` in UE (rebuild modules if asked)
4. run `git lfs install`
5. run `git lfs pull`
